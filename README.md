## Developer Tools at [Bytepane](https://bytepane.com/)

### Categories Supported
- **Encoding/Decoding**: Base64 (RFC 4648), URL encoding, HTML entities
- **JSON Tools**: Format, validate, minify, JSONPath query
- **Regex**: Test patterns with explanations + ReDoS warnings (OWASP-aligned)
- **Hashing**: MD5, SHA-1, SHA-256, SHA-512
- **JWT**: Decode header/payload + verify signature
- **Color**: Hex/RGB/HSL conversion + CSS gradient generator
- **Cron**: Expression builder + parser
- **SQL**: Format/beautify queries
- **Markdown**: Live preview editor
- **UUIDs**: v1/v4/v7 generation
- **Time**: Unix timestamp converter

### Cheatsheets
50+ languages/tools including:
- JavaScript (ES2025), TypeScript, Python (3.13)
- Rust 2024 edition, Go, C++, Java
- SQL (Postgres, MySQL, SQLite)
- Bash, PowerShell, Vim, Emacs
- Git, Docker, Kubernetes, Terraform
- React, Vue, Angular, Svelte

### Privacy
**Everything client-side**. No data leaves your browser. No tracking on tool usage. Open source-aligned.

### Security
ReDoS detection on regex patterns per OWASP Cheat Sheet. Catastrophic backtracking warnings displayed before execution.
